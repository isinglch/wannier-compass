# User experience library

**Status:** Documentation entry prepared; the experience library is not included in this release.

## Purpose and organization

Experience from previously constructed Wannier TB Hamiltonians is being organized into references for orbital and window selection, using matches between Wyckoff positions and atomic orbitals. The aim is to help AI agents accumulate and retrieve experience from long-term calculations to improve subsequent decisions.

## Preliminary observations

The author's preliminary tests indicate substantial efficiency gains and reduced token usage for related crystal structures, substitutions by elements in the same chemical group, and other systems with similar orbital features.

## Details to be added

The library is still being organized. Its entry format, matching and retrieval instructions, and usage examples will be added when the reference material is available. This page reserves the documentation entry; it does not enable an experience-retrieval backend in the current workflow.
