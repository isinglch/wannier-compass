# Window retry card

Read this card after an actual trial leaves an unaccepted fit or unconverged disentanglement. Use the current material's projected bands and its own recorded results. Begin with the diagnostic picture in the [construction overview](CONSTRUCTION-OVERVIEW.md): locate forced background or weak-support states, assess DIS space/data, then reassess the basis with independent evidence. Read spread together with fit and convergence. The [first-trial card](FIRST-TRIAL-CARD.md) supplies initial decisions; [stage records](DECISION-STAGES.md) define the retry commands and provenance.

## Choose and execute the next experiment

1. Record the preceding result. Identify technical failure, disentanglement convergence, and same-k fit residuals separately. Locate poor states in the declared target and note which are currently frozen. Read the original precision objective before choosing a direction.
2. Choose a result-driven hypothesis using the table below. These are candidate experiments, not automatic boundary changes.

| Current protection and evidence | Candidate experiment |
| --- | --- |
| Relevant low-conduction target states are not yet frozen | Inspect their raw target and competing projections on the full path. Review a frozen upper candidate that protects clean low-conduction target states using the first-trial positive-evidence procedure. Check every included path state and the actual interface state counts. Explain a deferral when evidence is unresolved. Start with this review rather than mechanically shrinking an already valence-only frozen window. |
| Frozen already protects substantial higher conduction states, and the fit is poor | Keep the basis and outer window fixed; try a moderately lower `frozen_max` to test whether releasing high-state constraints helps the declared objective. Choose the boundary from projected branches and preceding residuals; retain the released states in the target and outer space. They can still be legitimate target states. Record which states lose forced protection and what improvement is expected. |
| Outer space may be insufficient: target continuation above outer or little `N_outer-num_wann` headroom | Review a wider `dis_max` while holding frozen fixed. Use current projections and the previous fit to justify the candidate; the initial reference-weight heuristic need not be reapplied as a fixed retry bound. Check the physically chosen candidate against the path and actual interface band top. Insufficient DFT data requires more non-self-consistent bands, preserving the candidate. |

3. For a window-only experiment, keep basis, `num_wann`, exclusions, target, reference, DFT inputs, and iteration controls fixed. Prefer one boundary change so its effect can be interpreted. Reuse verified matrices when their input/basis/exclusion identity still matches. A model, task, or solver-control change is a separately declared scientific change. A narrower precision objective does not prescribe a frozen boundary at the same energy.

### Test an uncertain additional basis channel

An additional-channel witness establishes where a projection occurs. It does not prove that an explicit Wannier orbital is needed there: a reduced effective model may represent the same hybridized states. A converged larger model also does not establish necessity.

When the first trial retains an uncertain extra channel, compare its task-state contribution with the retained main channels and inspect the resulting lower branches. If the extra model mostly adds a concentrated lower block outside the physical objective, propose a reduced-basis counterfactual. Remove only the tested channel, regenerate its basis-dependent interface, and retain the DFT source, original physical evaluation and solver controls. Preserve the existing windows where feasible; if the smaller dimension makes a frozen interval impossible, declare the required boundary change and explain the resulting confound.

Keep original target-row and error accounting alongside any corrected core-task assessment. A scope correction must explicitly identify the lower block moved to background and report its omitted states; it cannot silently turn missing original states into a passed fit. Check relevant low conduction as well as occupied states. Prefer the smaller representation only when the declared task remains adequately described under the stated validation, and preserve uncertainty when neither trial establishes that result. This is a model experiment, separate from the frozen-only counterexample screen.
4. Write a new review with complete `window_override.dis_eV` and `window_override.frozen_eV` arrays and a reason. Run `propose → questions`, answer the latest questions, then re-propose and run fresh `questions → check` before sealing the new trial with its parent result. For the high-conduction constraint-release experiment, a clean higher frozen candidate may still be emitted: use `exploratory_defer`, `counterexample_k_band_1based: null`, and `trial_intent: {"mode": "exploratory", "reason": "the concrete previous-result hypothesis"}`. Also explain the first unprotected target state if requested. This records a result-driven deferral without misclassifying a target state as unwanted. The adopted window must still pass the existing negative screen and numerical gates.
5. Execute within the declared budget. Save the new selection figure, actual-interface checks, convergence, products, timing, and same-k comparison. Compare old and new trials over the **same declared target and precision region**, and retain errors over the original frozen region as a diagnostic. A lower error over only the new, smaller frozen interval does not establish improvement. Preserve a worse result; choose the next action from the full comparison and stop at acceptance, exhausted budget, or a documented data blocker.

## Scope of the negative screen

`frozen_state_counterexample_v1` checks a previously proposed window for weak-target or stronger-unselected states at every path k point. It can veto a candidate or require shrinking the adopted interval. A clean screen is compatible with either retaining protection or testing a result-driven relaxation; it does not choose that experiment, enlarge frozen, or remove orbitals. The high-conduction retry above uses previous fit evidence to test constraint pressure, not a fabricated negative projection witness. It carries no universal energy decrement or material-specific answer.
