# From projected bands to the VASP/Wannier90 interface

[Decision stages](DECISION-STAGES.md) govern execution. Proposals are drafts; new jobs require a sealed first try/retry. Initial is not executable directly; existing results remain readable.

The default route chooses orbitals/windows from SCF charge and projected bands, then performs one complete uniform-grid interface NSCF producing AMN/MMN/EIG. No preliminary independent mesh cache, PDOS, or WAVECAR is required. Actual interface counts/matrices are checked after generation.

For repeated bases at fixed physical settings/grid/NBANDS, prepare and seal shared waves once. A changed basis/exclusion still needs VASP `ALGO=None` for matching matrices, without reoptimizing waves. A window-only retry can [reuse verified matrices](WANNIER-EXECUTION.md).

## Default entry

Initialize the [material layout](MATERIAL-LAYOUT.md), then seal/select stages. The following reused-DFT example uses source links; new DFT uses returned 01/02 paths directly without adding a source link:

```bash
python tools/prepare_wannier_interface.py prepare \
  --band-dir /work/material/02_band/source \
  --scf-dir /work/material/01_scf/source \
  --cache /work/material/02_band/charge.npz \
  --analysis /work/material/03_wan_trial/trial_001/records/selection/analysis.json \
  --decision /work/material/03_wan_trial/trial_001/records/selection/decision.json \
  --mesh-kpoints /work/material/03_wan_trial/trial_001/records/interface_KPOINTS \
  --out-dir /work/material/03_wan_trial/trial_001/interface

python tools/prepare_wannier_interface.py validate \
  --trial-dir /work/material/03_wan_trial/trial_001/interface
```

mesh-kpoints provides sampling input, not preexisting DFT outputs. `--mp-grid NX NY NZ` is an alternative; consult CLI help for mutual exclusions. band-dir is mandatory. Optional mesh-dir is legacy reuse compatibility, not a selection prerequisite or a replacement for band evidence. The default mesh-dir-free route rejects reuse-wavecar.

## Sealed shared-WAVECAR route

Using the same SCF CHGCAR, prepare a complete automatic-Gamma zero-shift grid with ICHARG=11, ALGO=Normal, LWAVE=.TRUE., and sufficient NBANDS. Occupied and relevant empty-state waves must converge; CHGCAR with NELM=1 is not a substitute. Seal after completion:

```bash
python tools/shared_nscf.py seal --directory /work/shared_nscf/material \
  --scf-dir /work/material/01_scf/source --band-dir /work/material/02_band/source
python tools/shared_nscf.py verify --directory /work/shared_nscf/material
```

Waves generated by this toolkit's `dft_workflow.py prepare --stages scf band mesh` and run-stage mesh can be sealed directly from the case's `_optional_mesh`, with that same case's 01_scf/02_band. Verify the original pre-run case.json, post-run run.json, hashes, outputs, complete Gamma grid, and WAVECAR; do not fabricate legacy PREPARATION/process_exit records afterward. The independent shared-source route remains supported.

Sealing checks preparation/physical settings, SCF charge, grid, EIGENVAL, WAVECAR header/length, actual NBANDS, process status and OUTCAR convergence, binding input/output hashes. Only sealed sources qualify. This establishes wave-data identity, not a valid basis/window/fit. shared-nscf-preparation-v1 records original input hashes, grid, requested bands, and resources, without historical Wannier answers.

```bash
python tools/prepare_wannier_interface.py prepare \
  --band-dir /work/material/02_band/source \
  --scf-dir /work/material/01_scf/source \
  --cache /work/material/02_band/charge.npz \
  --analysis /work/material/03_wan_trial/trial_001/records/selection/analysis.json \
  --decision /work/material/03_wan_trial/trial_001/records/selection/decision.json \
  --shared-source /work/shared_nscf/material \
  --out-dir /work/material/03_wan_trial/trial_001/interface
```

Do not also pass mesh-kpoints/mp-grid. Copy original KPOINTS/WAVECAR with hash checks into a fresh trial; never symlink the trial WAVECAR to the shared source. Use ISTART=1, ALGO=None, NELM=1, LDIAG=.FALSE., LWAVE=.FALSE., LCHARG=.FALSE. VASP still generates basis-specific matrices/win. Check the pre-execution trial WAVECAR hash. A subsequent zero-byte VASP placeholder is accepted only when the official run record preserves that pre-execution hash; it is not a new wave source.

Require exactly one OSZICAR NONE record and no DAV/RMM/DIA/EIG wave optimization/recalculation records. Compare current EIGENVAL k order/state energies with the sealed source and check matrices/exclusions/windows. VASP performs program-level postprocessing, not zero work; rediagonalization/iterative wave optimization is prohibited. If shared NBANDS exceeds projected-band NBANDS, record both. Old path projections do not identify newly added high states; obtain current matching projections when needed. The two execution modes are explicit; legacy reuse-wavecar cannot bypass identity checks.

Set `require_shared_wavecar=true` in the private execution profile for a shared-WAVECAR benchmark; it rejects ordinary ISTART=0 interfaces at submission and execution. The optional Slurm reference profile is `sites/slurm-shared-wavecar.example.json`; shared-wavefunction reuse itself does not require that scheduler. Missing/insufficient sealed sources require preparation/sealing, not silent fallback to iterative NSCF. Other execution backends need the authenticated integration described in [INTERFACES](INTERFACES.md).

| Input | Check |
| --- | --- |
| Band cache, analysis, decision | sampling=band_path and original PROCAR/EIGENVAL/POSCAR hashes; selection comes from this path |
| Decision | proposed_trial, next_action=prepare_interface, path numerical checks, mesh_gate_pending=true; path counts permit preparation only |
| SCF/band provenance | Matching structure, potential, density; normal static completion/convergence; EF independently from SCF; check available source output hashes |
| Physical settings | Currently supported static nonmagnetic semilocal scalar/spinor; consistent ENCUT, XC, charge, spin/SAXIS/MAGMOM, LMAXMIX, LASPH, etc. |
| Uniform sampling | Automatic Gamma/Monkhorst or verifiable complete explicit grid; default route needs no precomputed waves/eigenvalues |
| Historical isolation | No old win/chk/successful basis/windows; do not inherit WANNIER90_WIN/LOCPROJ/SCDM settings |

LMAXMIX must already be adequate when SCF charge is generated; changing it at interface cannot recover lost density information or determine basis. Automatic scalar-density-to-SOC adaptation requires separate implementation; readable CHGCAR does not prove matching physical protocols.

## Preparation and interface execution

Copy current structure/POTCAR/SCF CHGCAR and generate KPOINTS, INCAR, wannier90.win.in, and trial_manifest.json. Do not precreate wannier90.win: VASP receives win.in through WANNIER90_WIN and generates actual geometry/k order. Prepared point order is not validated VASP output.

| Action | Scope |
| --- | --- |
| prepare_wannier_interface prepare | Fresh inputs/manifest; no VASP execution |
| dft_workflow submit-interface | Submission-script preview |
| submit-interface --execute | Actual submission; not execution/output success |
| run-interface | VASP within configured allocation, actual return/OUTCAR/products, official record |
| validate [--outputs] | Read-only checks; no VASP, missing-matrix generation, or substitute execution evidence |

Do not replace run-interface with validation, overwrite official evidence with a checker, fabricate zero return, or delete failed outputs. Recheck executed directories with validate rather than rerunning. Account checking and actual interface execution separately.

Default settings are ISTART=0, ICHARG=11, ISYM=-1, NSW=0, IBRION=-1, LWAVE=.FALSE., and LCHARG=.FALSE. NBANDS follows current actual band dimensions; NUM_WANN follows reviewed basis/spin. Interface settings:

```text
LWANNIER90 = .TRUE.
LWANNIER90_RUN = .FALSE.
LWRITE_MMN_AMN = .TRUE.
LWRITE_UNK = .FALSE.
NCORE = 1
KPAR = 1
```

Remove source NPAR. Within site limits, select ranks that do not inflate NBANDS through band parallelism and record allocation without editing source DFT/site. Custom launchers use {ntasks}. For multi-node matrix memory, balance_tasks_across_nodes=true selects NBANDS factors divisible by node count and writes ntasks-per-node. Legacy positive ntasks_per_node enables the same layout only when nodes×ntasks_per_node=ntasks. Non-srun multi-node launchers also require {ntasks_per_node}, e.g. ["mpirun","-np","{ntasks}","-ppn","{ntasks_per_node}"]. Verify layout and single MPI initialization; hostname alone does not verify VASP launch. Layout changes are technical retries preserving failed evidence and scientific parameters.

Both win.in and generated win require explicit unique num_iter=0; reject missing, nonzero, duplicated, or overriding entries. Enable write_hr/write_rmn/write_tb/bands_plot and bind them in manifests. DIS defaults/caps at 10000, allows a smaller dis-num-iter, and explicitly uses dis_conv_tol=1e-8/dis_conv_window=3. Execution flags lack of convergence by 2000. Fit/convergence retries cannot enable maximal localization; zero localization alone does not establish strict symmetry.

Native kpoint_path/bands_num_points come from current DFT bands. W90 rescales later-segment sampling; use [same-k comparison](WANNIER-COMPARISON.md) rather than assuming band.dat row alignment.

The manifest binds band evidence, SCF density, grid, basis/windows/dimensions, and hashes with actual-mesh checks pending. Existing directories are not overwritten. Preparation is not mesh/DIS/fit acceptance.

Use official EIGENVAL parsers and Nwann calculation. Do not reconstruct VASP win from outputs/manifest or rewrite manifests/hashes to certify mismatched data. For parser, periodic-coordinate, or output-option bugs, preserve files; repair a tool copy with a recorded diff/version/reproducible check, then regenerate/validate from originals. Unsupported reuse is a documented gap, not permission for an alternative bypass.

```bash
python tools/dft_workflow.py submit-interface \
  --trial /work/material/03_wan_trial/trial_001/interface --site sites/slurm.example.json
# Execute explicitly within authorization.
python tools/dft_workflow.py submit-interface \
  --trial /work/material/03_wan_trial/trial_001/interface --site sites/slurm.example.json --execute
```

Default interface NSCF directly generates matrices; add no extra selection mesh/PDOS. In shared mode, the single prior wave NSCF is reusable data preparation; subsequent matrix generation does not iterate bands.

## Post-interface gates and Wannier execution

Check return code, OUTCAR convergence, actual NBANDS, EIGENVAL, actual win, and matrices. interface_run.json separates matrix consistency, mesh_gate, and ready_for_wannier:

1. Geometry/atom order/grid weights match input; retain VASP actual k order.
2. AMN/MMN/EIG dimensions, indices, completeness, and finite values are valid; EIG agrees with this interface EIGENVAL, without requiring nonexistent earlier mesh outputs.
3. Every actual mesh k satisfies Nfrozen≤num_wann≤Nouter. Report min/median/max headroom and computed-top margin above physical dis_max. Path prechecks are insufficient. Missing waves/bands call for required data, not shrinking a justified outer.
4. Failure gives window_gate_failed/ready_for_wannier=false and retains evidence/cost. Diagnose the window and confirm band-space insufficiency before adding bands.

```bash
python tools/prepare_wannier_interface.py validate \
  --trial-dir /work/material/03_wan_trial/trial_001/interface --outputs

python tools/wannier_workflow.py prepare \
  --interface-dir /work/material/03_wan_trial/trial_001/interface \
  --out-dir /work/material/03_wan_trial/trial_001/wannier
python tools/wannier_workflow.py submit \
  --directory /work/material/03_wan_trial/trial_001/wannier \
  --site sites/slurm.example.json --execute
python tools/wannier_workflow.py inspect \
  --directory /work/material/03_wan_trial/trial_001/wannier
```

Only validated interfaces enter official W90 prepare/run, which rechecks win/identity/readiness; a grep-and-bare-run bypass is inadequate. Matrix checks do not certify projection rank or full-BZ accuracy. W90 execution uses fresh directories and records manifest/run. Its read-only entry is inspect, not validate; default one rank and explicit alternatives remain site-limited.

Report normal process termination, explicit DIS convergence, nonempty bound chk/hr/r/tb/band/kpt products, and fixed-target same-EF/same-k fit separately. All done or reaching the iteration budget does not establish convergence. Window-only reuse updates decision/actual-mesh gates/provenance; basis/exclusion changes require matching matrices. Distinguish total DFT bands, retained input bands, and num_wann.

Legacy mesh-dir with band-dir can inspect existing waves, but is not the default selection route. Preserve historical products. See [VASP band example](https://vasp.at/wiki/Si_bandstructure) and [LWANNIER90](https://vasp.at/wiki/LWANNIER90).

## Reviewed occupied-prefix exclusions

The default band route accepts reviewed decision.band_selection. exclude_bands uses original k-independent DFT indices through WANNIER90_WIN; do not edit matrices or generated win. expected.nbands is VASP total; expected.num_bands_retained and win.num_bands describe retained matrix space. Check EIG against full EIGENVAL through the recorded mapping.

Verify occupations/global gap on the actual interface. Path isolation alone is insufficient. exclusion_gate_failed blocks DIS even if matrices are formatted correctly; it requires a revised exclusion, not a claim that the material is impossible. exclusion_recovery proposes shorter prefixes including no exclusion. Review with path projections/gaps, revise decision/windows, and generate matching matrices in a new trial. Single-round tests report the needed revision without an implicit extra scientific trial. Legacy mesh compatibility does not support the new exclusion contract; no additional independent mesh/PDOS step is introduced.
