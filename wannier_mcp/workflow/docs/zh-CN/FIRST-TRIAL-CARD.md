# 首轮决策卡（人工阅读译文）

执行以[英文卡](../FIRST-TRIAL-CARD.md)为准。先读[构造概览](CONSTRUCTION-OVERVIEW.md)，理解模型、窗口取舍和结果诊断，再使用当前完整投影能带，构造主要任务轨道流形和相关低导带。先声明物理任务，再选基组和窗口；拟合与重试保持原任务。本卡不提供材料答案。

| 顺序 | 依据与动作 |
| --- | --- |
| 1. 任务 | 看组成、完整能带、占据和同态原始投影，明确所需态、相关低导带和具体集中的深能级块。先定锚点再加轨道。区分目标、DIS背景、拖尾参考和精度目标；缩小frozen不改变任务。 |
| 2. 基组 | 从所属区块的p/d/s和可用f出发。额外通道以独立任务态证据说明表示作用。深能级通道可不加入，但先检查其在剩余任务中的作用。全谱峰值很远不证明任务内没有贡献。不选轨道和exclude带分开。 |
| 3. 价带dis下沿 | 含下最低所需目标的完整包络，混杂背景留在DIS。exclude只用于明确非目标占据前缀且有安全采样全局隙，随后核查实际接口；没有该隙，保留原带继续。 |
| 4. 价带frozen下沿 | 保护可识别目标价带；会强制纳入非目标或弱投影下方态时再上移。对未保护目标给具体证据或物理取舍。若浅下沿仅因挑了上方行，审阅更深候选。两种下沿均不要求全局隙。 |
| 5. 导带dis上沿 | 用完整目标延续、参考域约70%/拖尾提示、候选上方全部投影和逐k计数定物理outer。区分延续、另一个块、尾部及未知。随后检查DFT是否够；不足时保留合理候选，补所需非自洽数据。态数过门不保证DIS空间充分。 |
| 6. 导带frozen上沿 | 金属/半金属EF+0.5、绝缘体CBM+0.5为起始选项。独立审阅低导带角色、持续所选支持、邻近背景及延展终点。明确实际来源；整条行的高能包络只是草稿事实。高上沿先需正面分支证据，最后再筛反例。 |
| 7. 标量审阅 | 看实际能量区间内所有保留态，分别审阅下方目标保护、背景纳入、上沿来源及反例。按当前候选和所需态定位下沿、上沿或内部混杂，不能按EF上下分。 |
| 8. 封存/计算 | 保存initial、审阅封存real_first_try；允许相同。运行授权接口和num_iter=0解纠缠，核查该接口自身的网格/矩阵/态数。固定任务拟合、缺失态、收敛及产物分开报告，必要时按重试卡继续。 |

去掉非目标深s，不要求把剩余p/d目标价带的frozen普遍缩到EF附近。保护可识别价带，真实混杂留DIS。为任务加入s，也不要求保护所有深s成键态。

较高frozen候选先有低导带角色、持续所选支持和背景分支的正面审阅。既有逐态反证筛查只负责frozen否决/审阅；无反例不是扩张证据，有反例也不直接决定基组。独立的基组重审可使用原始任务/投影证据。

Nfrozen>Nwann说明当前候选的强制保护与维度不兼容。先看实际强制纳入态及两端，再判断基组。低覆盖率也不自动证明基组不足。内部混杂可能使单一窗口无法保护所有所需态，应保留任务并报告限制。

工具顺序：证据/空白草稿 → 填现有review → propose生成选择图、scope audit和导带问题 → 看事实及图后改科学方案 → 回答最新问题 → 重新propose/check → 封存。直接propose时补运行selection_scope_audit.py。window_override保存完整dis/frozen数组及物理理由，不修改封存记录。

报告先给固定任务效果，再给frozen范围及样本数。reference与outer背景不自动成为评分目标。默认图为frozen±1、dis±3上下文；显示范围不定义选择或验收。

审阅提示要求物理判断，自动改变的变量为空，不批准科学结果。路径计数为预检查，实际接口计数仍须独立验证。没有统一frozen宽度。后续尝试看[重试卡](WINDOW-RETRIES.md)。
