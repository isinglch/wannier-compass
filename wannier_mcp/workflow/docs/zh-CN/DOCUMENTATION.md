# 文档语言与可复现性规范

英文是 MCP 指令、执行 Skill、命令参考及默认生成报告的主版本。执行文档的 docs 根目录存英文，zh-CN 子目录存同名中文阅读译本。仓库 README.md 是面向人的主页：简介和背景中英对照，后续内容中文；README.en.md 是完整英文项目页和安装包介绍，README.zh-CN.md 保留旧中文入口。展示页语言布局不改变执行指令的语言和权威。译本链接对应英文，并标记来源 SHA256，不另立决策规则。

仓库根目录 docs/ 下的展示案例，与 wannier_mcp/workflow/docs/ 中的执行参考分开。README 插图不是数值 policy、材料选择先验或盲测输入。准备新的选择测试时，应按声明的访问范围提供当前输入和执行工具，隔离历史案例与答案。共享账号不等于严格访问隔离。

先读 CONSTRUCTION-OVERVIEW，理解物理模型、窗口取舍、结果表现和诊断顺序，再读首次选择卡作具体决策；实际试算之后使用重试卡，复杂分支再读进一步参考。MCP read_text 有长度限制，next_offset 小于 total_chars 时须继续读取。默认入口指向英文。name_zh 等明确的本地化字段仅作展示。用户提交的理由与来源原文保持不变，不为统一语言重写封存记录。

CONSTRUCTION-OVERVIEW 提供物理图景；WORKFLOW-DECISIONS 定义判断顺序与判据范围；FIRST-TRIAL-CARD 和 WINDOW-RETRIES 给出执行摘要。工具及 policy/schema 定义数值检查和接口。区分原始投影、参考域覆盖、候选启发式、数值必要条件及外部验收。区分目标、参考域、精度任务和展示范围。能量默认 eV、相对声明的 SCF EF；倒空间坐标需说明基底，长度为含 2π 的 Å⁻¹，带号与路径切片遵守各自索引约定。路径证据不是接口网格检查，路径谱不是 BZ DOS；产物齐全、解纠缠收敛、拟合及对称性验收分别报告。

语言修改保留判据 ID、作用范围、阈值、schema 键、示例数值、采样与能量约定、迭代控制和计次。科学要求变更单独声明。检查链接、安装后的文档、清单哈希、数值 policy 和执行行为。复现使用实际内容哈希，不只使用版本号。

相同输入与数值程序保证确定性计算不因文档翻译改变；AI 决策可能随语言变化。对照须固定输入、模型设置、目标、预算和验收范围，使用等价新上下文，分别报告选择、拟合、成本和不确定性。翻译或接口测试通过不能证明科学成功率相同。中文差异应对照英文与实现修正；旧实验快照不覆盖。
