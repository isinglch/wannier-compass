# 窗口重试执行卡

实际试算未验收或解纠缠未收敛后阅读此卡。使用本次材料的投影能带和本轮已经登记的结果。先按[构造概览](CONSTRUCTION-OVERVIEW.md)的诊断图景定位强制纳入的背景或弱目标态、检查 DIS 空间与数据，再用独立证据重审基组；spread 与拟合、收敛一起看。[首次选择卡](FIRST-TRIAL-CARD.md)提供初选步骤；[阶段记录](DECISION-STAGES.md)定义重试命令与来源。

## 选择并执行下一项实验

1. 登记上一轮结果。分开判断技术故障、解纠缠收敛和同 k 拟合残差。定位声明目标中的问题态及其是否已冻结，先读取原始精度目标再决定改动方向。
2. 按下表选择一个有前轮结果依据的假设。表中动作是实验候选，工具不会自动移动边界。

| 当前保护范围与证据 | 候选实验 |
|---|---|
| 相关低导带目标态尚未冻结 | 查看完整路径上的目标原始投影与同态竞争，按首次选择的正面证据流程审阅保护干净低导带的上界候选。检查所有纳入的路径态和实际接口态数。不确定时说明暂缓理由；不要机械缩小已经只保护价带的 frozen。 |
| 已冻结较多高导带，拟合仍差 | 固定基组和 dis，试着适度降低 frozen 上沿，检验释放高态约束是否改善声明目标。边界依据投影分支及前轮残差；释放的态仍留在目标与 outer 中，可能仍是合法目标态。记录哪些态失去强制保护及预期改善。 |
| outer 上方有目标延续，或 N_outer−N_wann 余量很小 | 固定 frozen，审阅更大的 dis_max。以当前投影及前轮拟合解释候选，首轮参考权重启发式不用重新充当固定重试边界。物理候选确定后核对路径与实际接口带顶；数据不足则补必要非自洽空带，保留该候选。 |

3. 只改窗口的实验固定基组、num_wann、排带、目标、参考域、DFT 输入和迭代控制。优先一次改一个边界，复用输入／基组／排带身份一致的矩阵。模型、任务或求解控制变化另行声明为科学改动。精度区缩小不规定 frozen 必须缩到同一能量。
4. 新 review 中写完整 window_override.dis_eV、frozen_eV 及理由。propose → questions，填写最新问题，再重新 propose 并生成新 questions → check；关联父结果后封存新试次。若释放高导带约束后，工具仍提出干净的较高候选，使用 exploratory_defer、counterexample_k_band_1based:null，并写 trial_intent 的 mode:exploratory 及真实前轮假设。按要求解释第一个未保护目标态，不把合法目标伪称为非目标。已采用窗口仍须通过负面筛查和数值门槛。
5. 按声明预算执行。保存选择图、实际接口检查、收敛、产物、时间及同 k 拟合。新旧结果使用相同声明目标和精度区，并保留原 frozen 范围误差作为诊断。只在新小内窗内误差较低不能证明改善。劣化结果同样留档；在验收、预算耗尽或明确数据阻塞时停止。

## 负面筛查的用途

frozen_state_counterexample_v1 在已经提出的窗口中，逐路径 k 检查弱目标或未选轨道更强的态。它可否决候选或要求缩小已采用区间。无反例可以与维持保护或按结果释放约束同时成立，但不能决定下一项实验、扩大窗口或删轨道。释放高态保护依据前轮拟合检验约束压力，无须编造负面投影反例，也没有通用固定 eV 缩减量或材料答案。


### 检验尚不确定的额外基组通道

额外通道的投影见证只说明该处有投影，不证明必须增加显式 Wannier 轨道；较少轨道的有效模型也可能描述同一混合态。较大模型收敛也不证明额外通道的必要性。

首轮保留了尚不确定的额外通道时，应在任务态上比较它与主要保留通道的权重，并检查结果中的低能分支。若扩大模型主要增加了任务之外的集中低能谱块，可提出较小基组的对照尝试：只删除待检验通道，重生成与基组相关的接口，保持 DFT 来源、原物理评价范围和求解器设置。可行时保持原窗口；若轨道数变少使原 frozen 不可行，应明确记录必要的窗口改动及其造成的比较局限。

保留原目标带及误差统计，再并列评价经明确纠正的主体任务。范围纠正必须说明哪些低能谱块改为背景及哪些原目标态不再被描述；不得把漏掉的原目标态静默记作拟合通过。既检查占据态，也检查相关低导带。只有在明确验证范围内较小模型依然充分描述任务时，才支持较小表示；证据不足就保留不确定性。这是独立的模型对照实验，不属于 frozen 逐态否决判据。
