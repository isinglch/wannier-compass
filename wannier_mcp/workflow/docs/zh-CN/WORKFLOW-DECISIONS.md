# 轨道流形与窗口：唯一的决策顺序

本文定义科学选择的顺序和每一步的输出。命令及字段格式见 [MANIFOLD-SELECTION.md](MANIFOLD-SELECTION.md)；物理背景见 [PHYSICAL-REASONING.md](PHYSICAL-REASONING.md)。图、数值门槛和理由都只证明其各自检查的对象，不能代替整个模型的拟合验收。

## 输入与目标

输入是同一次计算的 SCF 能量参考、完整投影能带路径、逐态元素×s/p/d/f 原始权重、占据及带号。先声明模型必须复现的物理态和精度目标，再选择轨道表示并审阅完整的所需流形，包括相关导带。“完整目标”指所声明的物理任务，不等于每个化学满壳层或每个有非零投影的态。没有固定 `EF±1 eV` 选轨道区间；不额外要求投影 DOS 或独立 NSCF mesh。带号按各 k 点能量排序，不能当作已追踪的波函数分支。

最终确定轨道前，审阅候选深占据谱块的能量跨度、占据、逐态原始投影竞争、边界能隙及不同 k 点的成分变化。另行检查同一角动量通道在剩余目标价带和相关低导带中的角色，区分独立目标作用、次要杂化及尚未明确的耦合。深能级强峰和非零残余权重都不能单独决定是否保留基组通道。能量与投影连续性可提示角色交换，但不能证明波函数连接或独立局域流形。将这些判断写入现有的轨道及 target/reference 理由；省略基组、目标成员、可选排带和窗口下界仍是不同决定。

| 顺序 | 读什么证据 | 作什么决定并写入记录 |
|---|---|---|
| 1. 任务与轨道 | `review_packet` 全路径投影、独立任务锚点、集中的深谱块角色、原始权重与同态竞争 | 先声明任务范围，再从 p 区 p、d 区 d、s 区 s 出发审阅。额外通道给出深谱块之外的任务态及表示作用，逐个记录纳入/省略风险；深成键峰或没有 gap 不要求追加。仅有深作用的通道可省略，混合背景留在 dis。角色不明可显式探索。然后确定基组、`target`、`reference`；不能为凑 `num_wann` 倒推。省略主化学起点仍需核对最强参考态和物理角色。 |
| 2. 价带 | 目标权重的最低能量、保留的非目标/弱投影态的最高能量、占据、投影角色；全局隙和逐 k 直接隙只用于识别谱块及可选排带 | **先独立定三件事：** ① `exclude_bands` 可为空；仅在非目标低能连续前缀有清楚归属和采样全局隙时提出，接口网格再验，失败则缩短或撤销。② `dis_min` 从目标价带的完整投影包络下沿再留余量，允许包含一些非目标态以供解纠缠。③ `frozen_min` 从干净目标态开始：若下方保留的非目标态或弱投影态进入内窗，就上移下界，让它们只留在 outer。两下界**不要求处于同一隙，也不要求相等**；确有干净保护隙时可经明确审阅后共用。 |
| 3. 导带与 `dis_max` | 目标投影扩展、导带参考域每通道权重累积、outer 以上**全部已算带**的投影、长尾、每 k 态数与带顶余量 | 先以完整目标导带和 `N_outer≥N_wann` 决定下限，再用约 70%/拖尾提示选择有余量的起始上界。**计算参考域内覆盖率后，必须再看 outer 以上的全部已算投影带，包括自选参考行内的部分**：先用相邻分支和同态竞争判明上方已选投影的物理角色；确定是目标延续才重审目标/参考域并提出更高 outer 候选，另一谱块或弥散尾巴不因权重非零而无限扩大。`N_outer≥N_wann` 仅表示可执行，另审 `N_outer−N_wann` 是否过窄。疑问可以标记探索试算，不能缩窗掩盖已有目标态。只有实际带顶/态数不足才保持基组补所需非自洽。 |
| 4. `frozen_max` 正面选择 | 从金属/半金属的 EF、绝缘体的 CBM 附近开始，沿低导带逐段查看所选投影、未选投影、背景态及每 k 冻结态数；自选 target 行号不是物理排除证据 | 带边 `+0.5 eV` 是起步候选，不是终点或硬下限。把有目标角色、所选投影持续占主导且没有独立背景分支的低导带逐段纳入候选；在混合/角色交换或证据不足处停止并写具体态。若首个较高候选有正面目标证据且新增能量区间没有逐态反例，应实际提出一个更高 frozen 草稿供审阅，而不只是口头表示“可以考虑”。占据与否不能单独决定上界。`initial` 可保守，但若目标低导带留在外面，必须指出第一个未保护的目标态及其投影，明确为何暂缓。 |
| 5. 反证筛查 | **基组、目标、exclude、outer、正面 frozen 候选已固定后**，扫描候选窗口内所有路径 k 点的逐态原始投影和数值门槛 | `frozen_state_counterexample_v1` 只复核已提出的内窗：低端反例提示提高 `frozen_min`，高端反例可否决更高候选或提示降低 `frozen_max`；内部反例须审阅能否用一个标量窗口隔离。采用窗口内若仍有目标权重弱或未选轨道更强的反例，本轮状态为 `needs_window_review`；审阅具体态、移动内窗后重查。零反例没有创设新的扩大理由。它不增删基组，也不改 `target`、exclude 或 outer。 |
| 6. 提交与重试 | initial/real first try 两套选择图及警告，接口实际网格，Wannier 收敛和同 k 拟合 | `initial` 留底，审阅后选择首次实际试算；两者可以相同，但应记录为何保留。接口矩阵生成后用**该接口自身的网格**检查排带、态数和计算带顶。`num_iter=0`。重试先定位是错误基组、目标截断、错误冻结还是解纠缠空间不足；保持预先声明的目标范围评价，不通过缩小评价区改善成绩。 |

### 判据优先级

1. 输入身份、矩阵、窗口嵌套、态数、带顶和接口网格门槛是可执行性的**必要条件**；通过不证明物理正确。
2. 独立声明的任务决定基组范围，化学主起点只指导审阅，不要求保留全部成键壳层。额外通道需要任务相关证据；残余杂化允许较小基组假设，较强任务混合也可支持扩展或探索对照。不设普遍删 s 规则或固定 EF 能区。
3. 70%/长尾、带边 `+0.5 eV`、取整和余量是**候选生成器**，不能推翻完整目标包络，也不作拟合验收。
4. 逐态反证是**限定用途的负面复核**，只对已提出的 frozen 区间生效；低端和高端反例分别复核对应边界。物理证据与它冲突时写明位置和试算意图；不要跨步骤推导轨道或 outer。

### 价带下界的执行次序

先在投影能带上标明目标价带的最低态和保留的非目标/弱投影态。`dis_min` 必须在目标最低态以下并留起始余量；它框入少量背景不构成失败。再找一个能保护干净目标态、却不冻结下方背景的 `frozen_min`。若目标和背景能量交叠而没有一刀切的内窗，就保留目标于 outer，只冻结能明确识别的内部区域，记录未冻结的目标态与混合位置。最后才决定能否**另行**排除某段深能级：有占据、非目标归属、全局能隙时可提连续前缀；没有合格排带也继续做窗口和试算。这里的 0.1 eV 路径隙留量只约束当前工具的可选 `exclude_bands`，不是选择 `dis_min`、`frozen_min` 的阈值。

### 导带上界的执行次序

1. 在完整投影能带上标出已选壳层持续出现的导带及竞争壳层，声明 `target` 和用于观察尾部的 `reference`。带号是能量次序，交叉处要看图、能量范围和逐态权重，不能假装已经跟踪波函数。
2. 用目标带包络、`N_outer≥N_wann` 和参考域的 70%/长尾生成**起始** `dis_max`。此处的覆盖率分母只含自选参考带，不能当成整个已选壳层的覆盖率。
3. 看 `selection.json` 与 `review_diagnostics.md` 的 `upper_reference_audit`，再看完整投影图。核对当前上窗以上**所有已算态**（参考域内外都看）：既看**穿越上窗**的带，也看**刚在上窗以上出现**的高权重带。若确有目标角色分支延续，重新划定目标/参考域，提出能包住它的更高 outer 候选并重跑 `propose`；若主要是竞争轨道或弥散尾巴，写明依据后可维持当前上窗；若角色难分，记录不确定性并以明确的探索试算检验。若参考域触及最后算带，或候选探针高于部分路径 k 点的算带顶端，则所谓“长尾变弱”可能只是**右截断**；先补同设置的高带投影路径，再作完整性判断。这个审计只提供事实，绝不自动扩大窗口或基组。
4. **先定物理上需要的 outer，再审计 DFT 是否算得足够高。**对拟提交的上窗，用当前 band path 预检每 k 态数和最高算带余量；接口生成后再用**实际接口网格**复核。分别报告 band-path 投影证据的带顶与接口波函数的带顶：前者不足会使选窗证据缺失，后者不足会使 Wannier 解纠缠空间不完备。若已选 outer 到带顶的余量太小、甚至截断，保持物理方案，增加 NBANDS 并重算所需非自洽投影路径和/或共享接口波函数；**不得为了通过带顶门槛而缩小有目标依据的 `dis`**。在记录中保留该窗口，置 `status=needs_more_data`、`next_action=add_bands_nscf` 并标明缺的是投影路径、接口波函数还是两者；补完再重新核算和提交，不把 DFT 缺口伪装成较小的科学方案。几 eV 的余量也值得人工怀疑空态完备性；5–10 eV 可作审阅警报的量级，但不是通用硬阈值，更不是 `dis` 选择器。`window_checks` 给出逐 k 的 `N_outer`、`N_frozen`、`N_outer-num_wann` 和带顶余量的最小/中位/最大值；不能只看全局 NBANDS。即使顶端余量很大，若 `N_outer-num_wann` 接近零，解纠缠选择空间仍可能过窄。数值门槛通过只表示可执行。`frozen_max` 另由干净目标低导带提出，再用逐态反证筛查缩减或否决该候选；不要用 outer 的高能尾部决定 frozen。

## 每次必须留下的证据

保存 `review.json`、`selection.json`、`review_diagnostics.json`、标准 `selection.png/pdf`，并在 `initial`、`real_first_try` 和每次 retry 各自封存。图与方案的哈希绑定见[选择图集](SELECTION-GALLERY.md)；正式阶段与按标准目录命名的纯选择测试均默认更新同实验图集，其他布局可用图集 CLI 集中汇总。审阅具体带/k/投影，记录候选、采用值、理由和不确定性；`record_consistent` 只验记录与数值一致。真实运行后分别报告解纠缠状态、完整产物、固定目标范围的拟合与计算/token 成本；下一轮按[窗口重试卡](WINDOW-RETRIES.md)区分现有保护范围再提出实验。历史答案不进入选择包；已知材料重放只算开发集回归。
