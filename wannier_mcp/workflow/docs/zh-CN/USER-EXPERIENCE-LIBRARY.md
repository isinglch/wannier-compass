**状态：**说明文档入口已准备；本版本尚未提供经验库。

## 整理思路

根据已构造材料的经验，按 Wyckoff 位置与原子轨道的匹配关系，整理轨道选取和窗口选取的参考库。目标是让 AI 积累与检索长期计算经验，形成参考记忆，进一步优化判断能力。

## 初步观察

作者的初步测试显示，这类参考在同类晶体结构、同族元素替换等具有相似轨道特征的体系中，可显著提高构造效率并减少 token 消耗。
